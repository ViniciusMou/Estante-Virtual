# Estante Virtual

Este é um projeto simples de uma aplicação de gerenciamento de livros, onde o usuário pode cadastrar, listar, buscar e organizar livros de uma estante virtual.

## Funcionalidades

- Cadastro de livros
- Listagem de livros disponíveis
- Busca de livros por nome ou autor
- Remoção de livros
- Organização básica do acervo

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como executar o projeto

1. Clone o repositório:
git clone https://github.com/seuusuario/estante-virtual.git

2. Acesse a pasta do projeto:
cd estante-virtual

3. Abra o arquivo `index.html` no navegador.

## Objetivo

Este projeto foi desenvolvido com o objetivo de praticar lógica de programação, manipulação de arrays e objetos em JavaScript, além de estruturar um projeto simples no GitHub.
